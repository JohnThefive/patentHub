# PatentHuB
Aplicação em Python para automatizar a estruturação inicial de minutas de patentes (Relatório Descritivo) em conformidade com as diretrizes formais do INPI (Instrução Normativa INPI/PR nº 30/2013).

## 🚀 Funcionalidades Principais
- Formulário web guiado para coleta de dados técnicos de invenções.
- Validação estrutural de campos obrigatórios via Pydantic.
- Exportação automatizada para documento `.docx` formatado com base em template padronizado.

## 🛠️ Tecnologias
- **Frontend:** Streamlit
- **Modelagem e Validação:** Pydantic V2
- **Motor de Documentos:** docxtpl (Jinja2 + python-docx)
- **Testes:** Pytest
